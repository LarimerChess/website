Event sync setup

The club calendar supplies the event details. This extension uses your existing Facebook login; it never reads or stores your password.

Automatic sync requires a successful single-event pilot. New form settings require a new pilot.

Facebook form setup and diagnostics

Facebook changes its event forms. The selectors below must come from the signed-in group’s actual forms. Use Inspect this Facebook form in the toolbar popup after opening each form.

Prepare an event from the toolbar before setting verified to true. Confirm Mountain Time, the host group, every date and time, the venue, and the full description. Publish one event, then enable hourly sync.

Link an existing Facebook event

Use this for events that already exist, so the extension updates them rather than creating duplicates. The event’s title and dates must match the calendar before it can be linked.
